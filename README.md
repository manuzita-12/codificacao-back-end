# Codificação Back-End

## Objetivo
Este repositório tem como objetivo armazenar projetos, exercícios e códigos desenvolvidos durante o estudo de desenvolvimento back-end, focando em conceitos fundamentais, criação de APIs e estruturação de rotas e servidores.

---

## Conteúdo
- Configuração de ambiente e gerenciamento de pacotes
- Criação de servidores HTTP
- Estruturação de APIs RESTful com Express
- Manipulação de rotas e middleware
- Integração e testes de rotas

---

## Ferramentas & Tecnologias
- **JavaScript**: Linguagem de programação principal utilizada no desenvolvimento das aplicações.
- **Node.js**: Ambiente de execução JavaScript no lado do servidor.
- **Express**: Framework web para Node.js utilizado no gerenciamento de rotas e criação de APIs.
- **NPM**: Gerenciador de pacotes utilizado para instalar e gerenciar dependências do projeto.
- **Git e GitHub**: Ferramentas utilizadas para versionamento de código e controle de alterações.
