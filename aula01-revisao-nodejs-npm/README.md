## Conteúdo
- **Aula 01 - Revisão Node.js e NPM:**
  - Manipulação do módulo nativo `os` para diagnóstico do servidor.
  - Leitura de métricas de hardware: plataforma, núcleos da CPU, modelo, frequência e conversão de memória RAM para GB.
- **Estruturação de Servidores:** Criação e configuração de servidores HTTP com Node.js e Express.
- **Gerenciamento de Pacotes:** Utilização do NPM para inicialização e controle de dependências.

---

## Ferramentas & Tecnologias
* **JavaScript**: Linguagem principal para construção da lógica do servidor.
* **Node.js**: Ambiente de execução JavaScript no lado do servidor.
* **Express**: Framework web para gerenciamento de rotas e criação de APIs RESTful.
* **NPM**: Gerenciador de pacotes para instalação e gerenciamento de bibliotecas.
* **Git e GitHub**: Ferramentas para controle de versionamento e hospedagem do código.
